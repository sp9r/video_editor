## 3. 新しい動画を作る

1. 上部の「新規プロジェクト」を押す。
2. 未保存変更の確認が出た場合は内容を確認する。
3. 左の`+`を押し、動画、音声、画像を選ぶ。OSから左パネルへドロップしてもよい。
4. 素材をメディア棚からタイムラインへドラッグする。
   - 動画・画像: Vトラック
   - 音声・BGM・ナレーション: Aトラック
   - 字幕: Cトラック
5. `Ctrl+S`でプロジェクトを保存する。

プロジェクト拡張子は`.spectra`です。素材自体はコピー・変更・削除されません。

## 4. カット編集

### 移動

クリップ本体を左右へドラッグします。互換性のある別トラックへ上下に移動できます。

### トリミング

クリップの左端または右端をドラッグします。左端トリムでは表示開始と元素材の開始位置が同時に進みます。

### スナップ

クリップの移動とトリムは、近くにある他クリップの先頭・末尾、再生ヘッド、タイムライン先頭（0秒）に吸着します。吸着する距離は画面上で8pxで、ズームを変えても感覚は変わりません。移動では、動かすクリップの先頭と末尾のうち近いほうが合います。吸着中は、その位置にミントの縦線が出ます。リンクされた映像・音声のペアと無効なクリップは対象外です。

- `S`キーまたはマグネットボタンで、スナップのオン・オフを切り替えます。
- `Alt`を押しながらドラッグすると、その操作だけスナップしません。
- 離した位置は、線が出ていた位置とそのまま一致します。

### 分割

1. 分割したいクリップを選択する。
2. 再生ヘッドをクリップ内へ置く。
3. `Ctrl+K`を押すか、分割ボタンを押す。分割ツール（`C`）でクリップをクリックしても、その位置で分割できる。

ロック中のトラックは分割・削除・移動・Inspector編集のいずれも受け付けず、理由を通知する。

### 削除

- `Delete`: 選択クリップを削除し、空白を残す。
- `Shift+Delete`: 選択区間を削除し、後続を詰める。

### Undo / Redo

- `Ctrl+Z`: 元に戻す。
- `Ctrl+Shift+Z`または`Ctrl+Y`: やり直す。

## 5. 映像・画像を調整する

タイムライン上の動画または画像を選び、右のインスペクタを使います。

- 位置X/Y: 出力画面の中心からのpixel移動
- 拡大率: 1〜800%
- 回転
- 不透明度
- クロップ: 上下左右を0〜49%で非破壊調整

画像も動画と同じクリップとして扱います。長さを変更し、上位Vトラックへ置くとoverlayになります。

## 6. 音声を調整する

動画または音声クリップを選び、音声セクションを使います。

- 音量: dB
- パン: 左右
- フェードイン／フェードアウト
- トラックのミュート

最終書き出しでは48 kHz stereoへ揃え、複数音声をmixしてlimiterを適用します。

> [!WARNING]
> 現在のプログラムモニターは実装途中で、全音声トラックのリアルタイムmixと実波形表示はまだ完成していません。最終出力側のFFmpeg mixが正本です。

## 7. 字幕

### 手動追加

1. 再生ヘッドを字幕開始位置へ置く。
2. 「字幕を追加」を押す。
3. Cトラックの字幕を選択する。
4. 右側で本文、開始、長さ、見た目を編集する。

### SRT / WebVTT読み込み

タイムライン上部の「SRT/VTT読込」を押します。読み込んだcueはCトラックへ配置されます。

### 見た目と効果

- フォント、サイズ、太字、斜体
- 文字色、縁取り色／幅
- 影色／ぼかし
- 背景色／濃度
- 字間、行間、X/Y位置
- なし、フェード、ポップ、下からスライド、タイプライター

最終書き出しではASS/libassを使用します。ASSで文字単位表現ができないタイプライターは、安全な近似効果へフォールバックします。

### SRTを別途出力

書き出し画面で「SRTファイルも出力」を有効にすると、MP4と同じ名前のSRTを生成します。

### 字幕の文字数・横幅・行数

自動字幕を作るときは、次の3つを一緒に決めます。自動処理のダイアログと、字幕テンプレートの「生成設定」にあります。

- **最大文字数**: 1つの字幕に入れる文字数の上限。
- **横幅の上限（%）**: 文字を折り返す1行の幅を、動画の幅に対する割合で指定します。初期値は選んだテンプレートの字幕幅です。
- **最大行数**: 1つの字幕を何行以内に収めるか（1〜16）。

欄の下に「この設定では1行に約12文字、2行で約24文字まで」のように、いまのフォント・サイズ・字間・横幅から計算した目安が出ます（例: Noto Sans JP ExtraBold 120px、幅1920px、横幅80%なら1行に12文字）。

実際に使われる文字数の上限は「最大文字数」と「1行の文字数 × 最大行数」の小さいほうです。さらに、字幕を作る段階で、文節（英語は単語）を途中で切らずに折り返して最大行数に収まるかを確かめ、収まらない字幕は文節の区切りで複数の字幕に分けます。1つの文節だけで1行を超える場合に限り、その文節の中で折り返します。プレビューと書き出しは同じ折り返し処理を使うため、生成した字幕はどちらでも指定の幅と行数に収まります。生成した字幕には、選んだ横幅と最大行数が保存されます。

字幕を1つ選ぶと、Inspectorの「字幕テキスト」の下に「2 / 2行」のように現在の行数と上限が出ます。上限を超えると警告が出ます。上限は「文字スタイル」の「最大行数」で字幕ごとに変えられ、横幅は「字幕幅」で変えられます。長い字幕を幅と行数に収まるように自動で分割する機能はまだありません。単語境界の分割や結合で調整してください。

### 作成済みの字幕の設定を変更する

字幕を作ったあとでも、設定は後から変えられます。字幕トラックの見出しにある字幕アイコン、またはInspectorの「字幕テキスト」にある「字幕設定を変更…」を押します。対象は「この字幕トラックのすべて」か「選択中の字幕」です。パネルには、最大文字数、横幅の上限（%）、最大行数、区切り方式（ルール／高品質（自動）／LLM）、テンプレート、フォント・サイズ・色・縁取り・縦位置が並びます。開いたときの値は、そのトラックの字幕を作ったときの設定（または直前に変更した設定）です。

- **見た目だけの変更**（色、縁取り、縦位置、テンプレートの見た目など）は、すぐ反映します。
- **字幕の分け方が変わる変更**（最大文字数、横幅、最大行数、区切り方式、フォントサイズ）は、字幕を作り直します。音声は再認識しません。字幕が持っている単語（時刻つき）を使って、作成時と同じ区切り処理をもう一度かけます。単語と時刻の対応、字幕トラック、テンプレート、字幕ごとのスタイルは引き継がれます。
- どちらも元に戻す操作1回で戻せます。
- **手で編集した字幕は作り直しません。** 本文を手で直した字幕（単語情報が外れたもの）はその場所にそのまま残し、折り返しだけ新しい設定にします。残した件数は完了のメッセージに出ます（例: 手で編集した字幕3件はそのまま残しました）。作り直した字幕が、残した字幕と重なることはありません。
- 変更した設定は、次に自動処理を実行するときの初期値になります。

日本語の折り返しは、助詞・助動詞・語尾（の、を、ます、でしょうか など）を前の語につけ、行の長さが揃うように改行位置を選びます（「解説し／ます」「エントリーシート／を」のように、語の途中や助詞だけの行にはしません）。プレビューと書き出しで同じ改行になります。

### 自動処理と字幕テンプレート

1. 動画をVトラックへ置き、対象clipを1つ選択する。
2. 「自動処理」で自動字幕、Natural無音カット、処理デバイス、日本語／自動、高品質／ルール、字幕テンプレートを確認する。
3. user templateを選ぶと、そのstyle・maxChars・maxLines・segmentation設定が最初の字幕生成へ渡される。選択templateは成功した自動処理でlast-usedとして保存され、次回のdialogで復元される。
4. 完了後は新しい字幕trackへ一括適用される。既存字幕trackは上書きされない。

自動字幕はmain processが外部workerを起動するため、workerが見つからない環境では手動編集と既存projectの利用は継続できますが、自動字幕は利用できません。raw Whisper wordはsource truthとして保持されますが、文字単位のfine acoustic alignmentはありません。長い日本語raw wordの編集境界は手動修正可能な推定値です。

## 8. 保存、自動保存、別PCへの移動

- `Ctrl+S`: 現在のプロジェクトへ保存
- `Ctrl+Shift+S`: 別名保存
- `Ctrl+O`: プロジェクトを開く
- 編集中はrecovery dataを自動保存

`.spectra`には素材の絶対パスとプロジェクトからの相対パスを保存します。別PCへ移す時は、プロジェクトファイルと素材フォルダの相対配置を維持してください。

素材が見つからない場合、プロジェクトはoffline状態のまま開きます。メディア棚で赤い「オフライン」表示の素材を見つけ、「再リンク」を押して移動後のファイルを指定してください。タイムラインのclipは同じ素材IDを維持したまま、pathとmetadataを更新します。

## 9. 動画を書き出す

1. 右上の「書き出す」を押す。
2. YouTube 1080p、4K、縦動画、カスタムから選ぶ。
3. 幅・高さ、映像／音声ビットレートを確認する。
4. エンコーダーモードを選ぶ。
   - 自動: 利用可能なGPUを優先し、失敗時はCPU
   - ハードウェア優先: GPUを優先し、要件上の安全網としてCPUを残す
   - ソフトウェア: CPUのみ
5. 字幕の焼き込み／SRT出力を選ぶ。
6. 保存先を選び「書き出しを開始」を押す。

アプリは候補エンコーダーごとに短い実エンコードを行います。名前が列挙されただけのGPUは使用しません。書き出し失敗時は別の一時ファイルで次候補を試し、最後にCPUへフォールバックします。

実機の最終確認でGPU encoder probeが利用不可と判定された場合、画面にはCPU/libx264と表示されます。これは失敗を隠すものではなく、H.264/AACのCPU出力へ明示的に切り替える動作です。

# Stage 9: 自動字幕から全文修正まで

## 前提

自動字幕はvideo_editor単体に内蔵されたWhisperではありません。main processが、設定ファイル・環境変数・兄弟directory discoveryの順に`clip_automation`の`python`と`spectra_caption_worker.py`を探します。worker、Python依存、faster-whisper modelが利用できない場合は、手動編集・既存projectの利用は継続できますが、自動字幕だけが利用不可になります。

## 操作

1. 動画を読み込み、V1へ配置する。
2. 動画clipを1つ選び、「自動字幕」を押す。
3. 日本語、最大文字数32、最大行数2、高品質またはルール方式を選ぶ。
4. 生成完了後、字幕trackを確認する。
5. 必要に応じて字幕をRazor分割、結合、境界drag、Inspector本文編集する。
6. `Ctrl+Z` / `Ctrl+Shift+Z`で操作を戻す／やり直す。
7. 「全文修正」を開始し、通常の編集を終えたら「修正完了」を押す。
8. before/afterのwhole-track差分summaryを確認する。
9. 必要ならReview Modeで個別字幕をA/B/C/D評価する。

本文を編集して元のraw word連結と一致しなくなった字幕は、誤ったword timingを残さず本文編集可能な状態になります。これは推定境界を音響的真実として保存しないための仕様です。

## 制限

- workerのsource range結果はsource absolute microsecondsで返り、Studio側で`clip.startUs + (sourceUs - clip.sourceInUs)`によりtimelineへ変換します。
- raw Whisper wordは保持しますが、文字単位のfine acoustic alignmentはありません。SubtitleEditUnitの時刻は編集用推定値です。
- 自動字幕baselineとFull Correction artifactはuserDataへ保存されます。path、credential、media本体はartifactへ保存しません。
- 別PCへコピーするだけで使えるportable構成は未達です。worker discoveryとPython/Whisper環境のセットアップが必要です。
