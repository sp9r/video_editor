## 1. 起動

```powershell
cd C:\Users\谷本真幸\SynologyDrive\Storage\20_PC_Backup\C\Storage\30_Software\90_Self_Made\Apps\video_editor
npm.cmd install
npm.cmd run dev
```

初期画面にはUI確認用のデモプロジェクトが表示されます。実ファイルで編集する時は、新規プロジェクトを作成して素材を読み込んでください。

## 2. 画面構成

| 場所 | 役割 |
|---|---|
| 上部 | プロジェクト、ワークスペース、Undo／Redo、保存、書き出し |
| 左 | 動画・音声・画像を管理するメディア棚 |
| 中央 | 完成映像のプログラムモニターと再生操作 |
| 右 | 選択クリップの映像・音声・字幕設定 |
| 下 | 複数トラックのタイムライン |
| 最下部 | 選択数、再生位置、自動保存、GPU／CPU状態 |

## 3. 新しい動画を作る

1. 上部の「新規プロジェクト」を押す。
2. 未保存変更の確認が出た場合は内容を確認する。
3. 左の`+`を押し、動画、音声、画像を選ぶ。OSから左パネルへドロップしてもよい。
4. 素材をメディア棚からタイムラインへドラッグする。
   - 動画・画像: Vトラック
   - 音声・BGM・ナレーション: Aトラック
   - 字幕: Cトラック
5. `Ctrl+S`でプロジェクトを保存する。

プロジェクト拡張子は`.spectra`です。素材自体はコピー・変更・削除されません。

## 4. カット編集

### 移動

クリップ本体を左右へドラッグします。互換性のある別トラックへ上下に移動できます。

### トリミング

クリップの左端または右端をドラッグします。左端トリムでは表示開始と元素材の開始位置が同時に進みます。

### 分割

1. 分割したいクリップを選択する。
2. 再生ヘッドをクリップ内へ置く。
3. `Ctrl+K`を押すか、分割ボタンを押す。

### 削除

- `Delete`: 選択クリップを削除し、空白を残す。
- `Shift+Delete`: 選択区間を削除し、後続を詰める。

### Undo / Redo

- `Ctrl+Z`: 元に戻す。
- `Ctrl+Shift+Z`または`Ctrl+Y`: やり直す。

## 5. 映像・画像を調整する

タイムライン上の動画または画像を選び、右のインスペクタを使います。

- 位置X/Y: 出力画面の中心からのpixel移動
- 拡大率: 1〜800%
- 回転
- 不透明度
- クロップ: 上下左右を0〜49%で非破壊調整

画像も動画と同じクリップとして扱います。長さを変更し、上位Vトラックへ置くとoverlayになります。

## 6. 音声を調整する

動画または音声クリップを選び、音声セクションを使います。

- 音量: dB
- パン: 左右
- フェードイン／フェードアウト
- トラックのミュート

最終書き出しでは48 kHz stereoへ揃え、複数音声をmixしてlimiterを適用します。

> [!WARNING]
> 現在のプログラムモニターは実装途中で、全音声トラックのリアルタイムmixと実波形表示はまだ完成していません。最終出力側のFFmpeg mixが正本です。

## 7. 字幕

### 手動追加

1. 再生ヘッドを字幕開始位置へ置く。
2. 「字幕を追加」を押す。
3. Cトラックの字幕を選択する。
4. 右側で本文、開始、長さ、見た目を編集する。

### SRT / WebVTT読み込み

タイムライン上部の「SRT/VTT読込」を押します。読み込んだcueはCトラックへ配置されます。

### 見た目と効果

- フォント、サイズ、太字、斜体
- 文字色、縁取り色／幅
- 影色／ぼかし
- 背景色／濃度
- 字間、行間、X/Y位置
- なし、フェード、ポップ、下からスライド、タイプライター

最終書き出しではASS/libassを使用します。ASSで文字単位表現ができないタイプライターは、安全な近似効果へフォールバックします。

### SRTを別途出力

書き出し画面で「SRTファイルも出力」を有効にすると、MP4と同じ名前のSRTを生成します。

## 8. 保存、自動保存、別PCへの移動

- `Ctrl+S`: 現在のプロジェクトへ保存
- `Ctrl+Shift+S`: 別名保存
- `Ctrl+O`: プロジェクトを開く
- 編集中はrecovery dataを自動保存

`.spectra`には素材の絶対パスとプロジェクトからの相対パスを保存します。別PCへ移す時は、プロジェクトファイルと素材フォルダの相対配置を維持してください。

素材が見つからない場合、プロジェクトはoffline状態のまま開きます。メディア棚で赤い「オフライン」表示の素材を見つけ、「再リンク」を押して移動後のファイルを指定してください。タイムラインのclipは同じ素材IDを維持したまま、pathとmetadataを更新します。

## 9. 動画を書き出す

1. 右上の「書き出す」を押す。
2. YouTube 1080p、4K、縦動画、カスタムから選ぶ。
3. 幅・高さ、映像／音声ビットレートを確認する。
4. エンコーダーモードを選ぶ。
   - 自動: 利用可能なGPUを優先し、失敗時はCPU
   - ハードウェア優先: GPUを優先し、要件上の安全網としてCPUを残す
   - ソフトウェア: CPUのみ
5. 字幕の焼き込み／SRT出力を選ぶ。
6. 保存先を選び「書き出しを開始」を押す。

アプリは候補エンコーダーごとに短い実エンコードを行います。名前が列挙されただけのGPUは使用しません。書き出し失敗時は別の一時ファイルで次候補を試し、最後にCPUへフォールバックします。

# Stage 9: 自動字幕から全文修正まで

## 前提

自動字幕はvideo_editor単体に内蔵されたWhisperではありません。main processが、設定ファイル・環境変数・兄弟directory discoveryの順に`clip_automation`の`python`と`spectra_caption_worker.py`を探します。worker、Python依存、faster-whisper modelが利用できない場合は、手動編集・既存projectの利用は継続できますが、自動字幕だけが利用不可になります。

## 操作

1. 動画を読み込み、V1へ配置する。
2. 動画clipを1つ選び、「自動字幕」を押す。
3. 日本語、最大文字数32、最大行数2、高品質またはルール方式を選ぶ。
4. 生成完了後、字幕trackを確認する。
5. 必要に応じて字幕をRazor分割、結合、境界drag、Inspector本文編集する。
6. `Ctrl+Z` / `Ctrl+Shift+Z`で操作を戻す／やり直す。
7. 「全文修正」を開始し、通常の編集を終えたら「修正完了」を押す。
8. before/afterのwhole-track差分summaryを確認する。
9. 必要ならReview Modeで個別字幕をA/B/C/D評価する。

本文を編集して元のraw word連結と一致しなくなった字幕は、誤ったword timingを残さず本文編集可能な状態になります。これは推定境界を音響的真実として保存しないための仕様です。

## 制限

- workerのsource range結果はsource absolute microsecondsで返り、Studio側で`clip.startUs + (sourceUs - clip.sourceInUs)`によりtimelineへ変換します。
- raw Whisper wordは保持しますが、文字単位のfine acoustic alignmentはありません。SubtitleEditUnitの時刻は編集用推定値です。
- 自動字幕baselineとFull Correction artifactはuserDataへ保存されます。path、credential、media本体はartifactへ保存しません。
- 別PCへコピーするだけで使えるportable構成は未達です。worker discoveryとPython/Whisper環境のセットアップが必要です。
